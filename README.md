# Ebran Husain — Cinematic 3D NOC Portfolio

## Run locally

Because this project uses ES modules and Three.js, run it through a local web server.

### Option 1 — VS Code

Install the **Live Server** extension and open `index.html` with Live Server.

### Option 2 — Python

From this folder:

```bash
python -m http.server 5500
```

Then open:

http://localhost:5500

## Resume

Put the final PDF at:

`resume/Ebran-Husain-CV.pdf`

The Download CV button already points to that path.

## Notes

- Three.js and post-processing are loaded from jsDelivr.
- The monitoring values shown in the cinematic dashboard are illustrative visuals, not real production telemetry.
- Add real LinkedIn/GitHub URLs only when you have them.
- The 3D scene is intentionally generated procedurally so the project runs without large external model files.
